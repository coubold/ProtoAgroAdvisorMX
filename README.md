# AgroAdvisor MX · prototipos

Prototipos de Bold para BBVA México. Todo es simulado.

- `index.html`: tablero mensual de la cartera FIRA (producto 2, Seguimiento Central).
- `verificacion.html`: verificación por crédito con informe pre-visita y carga del resultado de la visita (producto 1). Se abre desde "Ver informe" en el tablero o directo para cargar un crédito a mano.

## Publicar en GitHub Pages

1. Crear el repo y subir estos archivos en la raíz (Add file → Upload files).
2. Settings → Pages → Source: Deploy from a branch → Branch: `main`, carpeta `/ (root)` → Save.
3. En uno o dos minutos queda en `https://<usuario>.github.io/<repo>/`.

Ojo: el sitio de GitHub Pages es público aunque el repo sea privado (salvo GitHub Enterprise).
